# 实现说明

`launcher.py` 提供 Tkinter 界面和 CLI。它识别主包 manifest、内置 Java 版本及 JVM 配置，用参数列表启动原安装目录的 Java，并仅为这个子进程添加 agent。工具设置保存在 `%LOCALAPPDATA%/CubeMX-CN`。

`agent/src` 中的 agent 使用 instrumentation 和 JDK 内置 ASM，为 Swing 文字测量、绘制方法以及 `BasicHTML.createHTMLView` 增加入口转换。`agent/bootstrap` 中的翻译器单独打包，供 `java.desktop` 调用。没有磁盘补丁，也不修改控件原始 `getText()` 或 action command。

普通文字按词库精确匹配，兼容首尾空白和末尾冒号/省略号。HTML 只处理文本节点，保持标签和链接属性。编辑框与文件选择器内容排除在翻译外；显示字体必要时回退至中文字体。快捷键仍使用原英文键位。

界面显示层与业务字符串模型保持分离，但这不等于所有业务流程已完成回归验证。自定义绘制、原生窗口、图片、动态文本和线上内容可能绕过现有钩子。复制、搜索和无障碍接口也可能仍返回英文。

JDK 内部接口不是稳定公共 API，所以目前只支持 Java 21；其他 JRE 或 CubeMX 版本需要单独验证。

## 词库来源

初版对一个合法本地安装的主包及插件进行只读 ZIP/class 格式解析；没有启动原生反编译引擎。扫描 66 个归档、7,105 个 ST 命名空间类，获得 28,414 个唯一字符串。最终人工选择的 1,122 个键中，985 个具有完整常量证据，137 个仅具有 HTML 文本节点证据。字符串总数不是 UI 文案总数，不能用于计算汉化覆盖率。

可通过 `tools/extract_strings.py` 在自己的安装上复现提取。完整本地证据和日志默认不纳入 Git，也不随发布包分发。

# 验证范围

本地验证环境：Windows 11 x64，Python 3.12.5，Java 21.0.10；传统版 CubeMX 内部组件版本为 `6.18.1-RC2`，版本信息来自包元数据与运行日志。

已完成：

- 启动器测试覆盖安装识别、版本限制、坏词库拒绝、英文模式、参数列表与中文空格路径、原安装文件不改写、启动后元数据写失败及早退检测。
- Java 实际渲染测试使用 1,122 条词库，分别在普通路径和中文空格路径下运行，验证 JLabel/JButton 中文像素、宽度、HTML、原文本、按钮命令、编辑框排除、引脚与代码 token、快捷键。
- 真实 CubeMX 首页启动及截图确认，菜单、首页入口和 HTML 标题显示中文；启动日志未出现汉化层相关 Java 异常。
- 初次运行前后重新计算主包与插件 66 个归档的 SHA-256，全部保持一致。
- Windows EXE 启动器实际打开；高 DPI 布局已根据控件请求尺寸调整，最后一次尺寸调整没有再次完成截图验收。

未完成：所有 MCU/外设页面、完整工程保存、代码生成、打印/导出、无障碍接口，以及其他 CubeMX/JRE 版本的回归测试。`READY` 日志只证明代理已加载，不代表全部应用功能验证通过。

GitHub Actions 在不安装 CubeMX 的环境执行构建、测试和打包，用于验证源码的可构建性。它不能替代真实 CubeMX 的业务回归测试。截图中本地工程列表已隐藏。
